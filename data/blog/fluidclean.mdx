### 1. One-Tap Device Cleanup & Real Storage Reclamation

* **Physical Disk Operations:** Scans and removes real app caches, residual temporary files (`.tmp`, `.log`, `.bak`, `.crdownload`), empty directories, and obsolete installer packages (`.apk`).
* **Accurate Telemetry:** Powered by Android `StatFs` and `ActivityManager` to report actual physical storage space and RAM usage before and after cleanup—no fake stats or inflated numbers.
* **Live Counter:** Features smooth visual progress tracking with a real-time "freed space" counter and immediate storage gauge updates.

### 2. Duplicate Photo & Document Detection

* **Real File Scanning:** Scans internal and public storage directories, including `DCIM`, `Pictures`, `Documents`, and `Downloads`.
* **Exact Binary Matching:** Groups redundant files by checking file sizes and exact binary structures.
* **Original File Protection:** Intelligently preserves primary original files while pre-selecting redundant copies for safe, effortless removal.
* **Categorized View:** Filter results across Duplicate Photos, Duplicate Documents, App Cache, and All Items.

### 3. Liquid Battery Health Monitoring Dashboard

* **Glassmorphic UI:** Designed with a clean glassmorphic card layout and a fluid wave animated capsule.
* **Live Charge Percentage:** Direct hardware telemetry via Android `BatteryManager`.
* **Thermal Sensor Monitoring:** Real-time battery temperature monitoring in both Celsius (°C) and Fahrenheit (°F) with thermal state safety alerts.
* **Smart Estimates:** Calculates battery runtime based on current discharge rates or remaining charge time when plugged in.

### 4. Interactive Rocket Booster Overlay

* **Physics-Animated Launch:** A launching rocket animation that starts at the bottom, hovers near the screen center, flares up booster flames, and accelerates past the top edge.
* **Performance Summary:** Displays a glassmorphic performance card highlighting your percentage speed improvement and exact megabytes freed.
